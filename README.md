# ArchUnitSharp

Architecture testing for C# and .NET — a fluent, chainable rule DSL over a graph of your project's
files and their dependencies, in the spirit of ArchUnit.

This repository is being built from scratch, issue by issue, by the
[ArchUnitDev](https://github.com/RobeyBeswick/ArchUnitDev) loop. The backlog is a dependency-ordered
issue list; the conventions it builds against are in [AGENTS.md](AGENTS.md).

## Status

Under construction. The issue queue is the roadmap.
